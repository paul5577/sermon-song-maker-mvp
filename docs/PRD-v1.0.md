# PRD — 설교찬양 영상 자동 생성 웹앱

> 문서 버전: v1.0  
> 작성일: 2026-08-07  
> 프로젝트 가칭: **Sermon Song Maker / 설교찬양 영상 생성기**  
> 핵심 시리즈명: **설교가 찬양이 되다**

---

## 1. 제품 개요

### 1.1 목적
주일예배, 수요기도회, 금요기도회 등에서 들은 설교 말씀을 바탕으로 제작한 MP3 찬양을 스마트폰에서 업로드하면, 유튜브용 16:9 MP4 영상을 자동 생성하는 모바일 우선 웹앱을 개발한다.

사용자는 예배 후 이동 중에도 스마트폰으로 다음 작업을 완료할 수 있어야 한다.

**MP3 선택 → 예배 정보 확인/입력 → 영상 만들기 → MP4 완성 → 유튜브 업로드 정보 복사**

초기에는 개인용 도구로 시작하되, 향후 교회·목회자·찬양 제작자를 위한 SaaS로 확장 가능한 구조로 설계한다.

---

## 2. 핵심 문제

현재 설교찬양 영상 제작은 다음 과정을 거친다.

1. MP3 다운로드
2. Canva/Movavi 등 편집 앱 실행
3. 배경 이미지 삽입
4. 인트로 제작
5. MP3 길이에 맞게 본문 영상 조정
6. 아웃트로 제작
7. MP4 내보내기
8. 썸네일 제작
9. 유튜브 제목·설명·태그 작성
10. 업로드

이 과정은 모바일에서 번거롭고, 설교찬양이 꾸준히 쌓일수록 반복 작업량이 커진다.

### 목표
위 과정을 다음 수준으로 단축한다.

**MP3 선택 → 정보 확인 → 영상 만들기**

## 8. 기존 설교찬양 아카이브

이전에 제작된 약 20~30개의 설교찬양 MP3도 나중에 영상으로 변환할 수 있도록 한다.

### 기존 자료 정리 권장 필드
- 예배 날짜
- 예배 구분
- 설교 시리즈/강해명
- 본문
- 설교 제목
- 찬양 제목
- 설교자
- MP3 파일

### 운영 원칙
- 기존 곡을 한꺼번에 공개하지 않는다.
- 웹앱 완성 후 1~2곡씩 자동 변환한다.
- 주 2~3편 수준으로 예약 업로드한다.
- 과거 영상도 원래 설교 날짜를 유지한다.


- 날짜 → 2026.08.02
- 예배 구분 → 주일예배

# 최종 목표

이 웹앱의 장기적인 의미는 단순한 MP3→MP4 변환기가 아니다.

매주 예배에서 받은 말씀을

**예배 → 설교 → 묵상 → 찬양 → 영상 → 기록**

으로 이어주는 **신앙 콘텐츠 아카이브 시스템**을 만드는 것이 최종 목표다.

특히 성경 강해가 이어지는 경우,

- 창세기 강해 찬양
- 고린도전서 강해 찬양
- 베드로전서 강해 찬양

과 같이 시간이 지날수록 하나의 체계적인 설교찬양 라이브러리로 축적될 수 있도록 설계한다.
